# Mobile header fit

Fix for the wrapped Ilhabela Trip brand on narrow phones. Vertically center the header contents, tighten mobile spacing, keep the brand on one line, and use a 16px title with a 32px brand mark at widths up to 380px. Contact retains its 44px target; the language selector also has a 44px minimum height. Only the decorative dropdown chevron is hidden on the narrowest screens. Mobile rules apply to PT/EN home and Services; desktop styling remains as before.

Validation: four focused Playwright tests passed. Header coverage spans 320, 330, 360, 390 and 1440px in PT, EN, ES, FR and HE/RTL. Assertions cover single-line title, vertical alignment, control containment, non-overlapping header items, language menu, contact dialog, keyboard and focus. EN home and Services also checked at 320px. PT 330px and HE 320px screenshots visually reviewed. Existing contact/context tests passed. No real form submissions.

Screenshots are generated by tests/contact-header.spec.cjs; representative narrow captures are included here. Production is unchanged pending review.
